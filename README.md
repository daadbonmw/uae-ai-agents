# UAE AI Agents

Prototype AI agents that help people in the UAE get real things done with government and daily life.

Open the demos: the GitHub Pages site for this repository (see the "About" box).

| Demo | What it does |
|---|---|
| `answers/` | UAE rules, answered: a personal plan with steps, fees, deadlines and contacts, plus an official source for every fact |
| `city-repairs/` | City repairs, proven fixed: a case closes only when an after-photo proves the repair |
| `message-check/` | Is this message real? Warning signs for suspicious SMS and WhatsApp messages |
| `wages/` | Wage protection: log paydays, spot unpaid salary, build a case file |
| `rent/` | Dubai rent renewal check under the RERA rules |
| `careers/` | Emirati careers coach in English and Arabic |

Each demo is a single web page that runs in any browser, with nothing to install. Without an AI connected, built-in rules run and say so.

General information from official sources, not legal advice.
